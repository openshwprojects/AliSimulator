Source: not recorded.  The file is Strong's firmware update for the Strong Prima VIII DVB-T
HD receiver (ALi M3801, main board MC6501-M3801 VER1.0: the box of dumps/STRONG PRIMA VIII/),
version 1.0.6 of 14 January 2016 -- the "update v1.0.6" that box's owner on elektroda says he
downloaded (see the GD25Q32B note there).  It was added to this repository on 2026-01-20
("Create SRT_Prima_VIII_V1.0.6_20160114.abs") without a note of where it was downloaded
from.  Size 4194304 bytes, SHA-1 63861e2ebc24bc2e99df66c9511dc4d9eb6223fd.

Despite the .abs name it is a complete 4 MB flash image with the M3801 chunk chain: the
bootloader chunk at 0 (1.0.0, 2009-06-18, next chunk at 0x01FE00) like the box's flash dump,
newer main code, no user database.

In the simulator: run_dump_Prima_to_check_program.py, run_dump_Prima_to_print_success.py and
run_dump_Prima_to_main_app.py boot it through the bootloader ("bl_flash_init!",
"bl_verify_sw", "check_program!", "success!") into the main application.
